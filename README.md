# Restricted Web Proxy Starter

Educational Node.js site demonstrating a server-side request to a fixed site (https://example.com).

## Run
1. Install Node.js 18 or newer.
2. Open a terminal in this folder.
3. Run `npm start`.
4. Visit http://localhost:3000.

## Deploy
Create a Node.js web service on a host that supports Node (not GitHub Pages). Upload these files, set the start command to `npm start`, and use its public URL. Most hosts set the PORT environment variable automatically.

## Scope
This is a restricted **demonstration**, not an arbitrary-URL/open web proxy. It does not bypass school restrictions, host third-party login sessions, or support browser extensions like FUTGenie. Do not turn it into a public open proxy: SSRF, abuse, bandwidth costs, and credential exposure become risks.
